# AFK Farm Telegram Notifier

Клиентский Fabric-мод для **Minecraft 26.2**. Следит за игроком на AFK-ферме
и шлёт уведомления в Telegram: получил урон, умер, отключился от сервера.

Токен бота и chat_id вводятся **прямо в игре** — конфиг руками править не нужно.

## Что умеет

- **Урон** — сколько HP снято и сколько осталось. Сообщения троттлятся, чтобы яд и горение не заспамили чат
- **Смерть** — с текстом death message, если клиент его знает
- **Отключение** — с причиной кика
- **Подключение** — с адресом сервера
- Каждое событие отключается отдельной галочкой
- Кнопка проверки связи в настройках — покажет ошибку от Telegram (`401` — неверный токен, `400 chat not found` — неверный chat_id), не дожидаясь реального события

```
🩸 Получен урон              💀 Бот для фарма умер
🕐 05.08.2026 14:30:12       🕐 05.08.2026 14:31:02
💥 Урон: 3 HP                📜 Steve was slain by Zombie
❤️ Текущее HP: 17/20
```

## Установка

Скачать jar из [Releases](../../releases) и положить в `mods/` вместе с зависимостями:

| Требуется | Версия |
|---|---|
| Fabric Loader | 0.19.3+ |
| Fabric API | 0.156.0+26.2 |
| Cloth Config API | 26.2.155 |
| Mod Menu | 20.0.1 |
| Java | 25 |

Cloth Config обязателен — без него мод не запустится. Mod Menu нужен, чтобы
открыть экран настроек.

## Настройка

**Mods → AFK Farm Telegram Notifier → шестерёнка**

Токен получить у [@BotFather](https://t.me/BotFather), chat_id — через
`getUpdates`. Пошагово расписано в [USAGE.md](USAGE.md#настройка).

## Управление

Глобальный выключатель дублирован тремя способами:

| Способ | Как |
|---|---|
| Хоткей | **F6** (переназначается в Управление → Разное) |
| Чат | `#tgnotification true` / `false` |
| Команда | `/tgnotification` — с автодополнением по Tab |

## Сборка

На хосте нужен **только Docker** — ни JDK, ни Gradle ставить не требуется:

```bash
./build.sh          # → build/libs/afk-notifier-1.0.1.jar
```

Подробности, сборка начисто и запуск без `build.sh` — в
[USAGE.md](USAGE.md#сборка).
