# AFK Farm Telegram Notifier — сборка и использование

Клиентский Fabric-мод для Minecraft **26.2**. Следит за игроком на AFK-ферме
и шлёт уведомления в Telegram: урон, смерть, подключение и отключение от сервера.

---

## Сборка

На хосте нужен **только Docker**. Ни JDK, ни Gradle ставить не требуется —
всё собирается внутри контейнера.

```bash
./build.sh
```

Готовый мод появится на хосте в:

```
build/libs/afk-notifier-1.0.1.jar
```

Рядом лежит `afk-notifier-1.0.1-sources.jar` — он не нужен, в `mods/` кладётся
только первый.

### Что делает build.sh

1. Если `gradlew` / `gradle-wrapper.jar` отсутствуют (свежий клон), генерирует
   их во временном контейнере с образом `gradle:9.5.1-jdk25`.
2. Собирает образ `afk-notifier-build` — внутри выполняется `./gradlew build --no-daemon`.
3. Запускает контейнер с bind-mount на `build/libs` и выкладывает jar на хост.

### Сборка начисто

```bash
docker build --no-cache -t afk-notifier-build .
docker run --rm -v "$PWD/build/libs:/out" afk-notifier-build
```

Полностью сбросить кэш Gradle между сборками:

```bash
docker builder prune --filter type=exec.cachemount
```

### Вручную, без build.sh

```bash
docker build -t afk-notifier-build .
docker run --rm -v "$PWD/build/libs:/out" afk-notifier-build
```

> На Windows в Git Bash перед `docker run` нужен `MSYS_NO_PATHCONV=1`, а путь —
> в виде `E:/projects/...`. `build.sh` делает это сам через `cygpath`.

Мод в контейнере **не запускается** — это клиентский мод, контейнер нужен
только для компиляции.

## Установка

В папку `mods/` вашего клиента положите:

| Мод | Версия |
|---|---|
| `afk-notifier-1.0.1.jar` | собранный тут |
| Fabric API | `0.156.0+26.2` |
| Cloth Config API | `26.2.155` |
| Mod Menu | `20.0.1` |

Плюс сам **Fabric Loader 0.19.3+** и **Java 25**.

Cloth Config обязателен — без него мод не запустится. Mod Menu формально
опционален, но без него не открыть экран настроек.

## Настройка

Все настройки задаются **в игре**, файл руками править не нужно.

### 1. Получить токен бота

1. Написать [@BotFather](https://t.me/BotFather) в Telegram.
2. Команда `/newbot`, задать имя и username бота.
3. BotFather пришлёт токен вида `123456789:AAH...`.

### 2. Узнать chat_id

- **Личные сообщения:** написать боту любое сообщение, затем открыть
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id":...}`.
- **Группа:** добавить бота в группу, написать туда сообщение и посмотреть тот же
  `getUpdates`. У групп `chat_id` отрицательный — минус тоже часть значения.

### 3. Ввести в игре

**Mods → AFK Farm Telegram Notifier → шестерёнка**

**Основное:**
- `Включить мод` — глобальный выключатель.
- `Токен Telegram-бота` — вставить токен. Не показывайте это поле на стриме и скриншотах.
- `Chat ID` — id получателя.
- `Отправить тестовое сообщение` — см. ниже.

**События:**
- Отдельные галочки на урон, смерть, отключение и подключение.
- `Троттлинг урона (мс)`, по умолчанию 3000 — минимальный интервал между
  сообщениями об уроне, чтобы яд и горение не заспамили чат.

Настройки применяются и пишутся в `config/afk-notifier.json` по кнопке
**Save** на экране Cloth Config.

Если токен или chat_id пустые — мод работает, но ничего не отправляет
и один раз пишет предупреждение в лог.

### 4. Кнопка Test

Проверяет связку токен + chat_id, не дожидаясь реального события.

- Берёт значения **прямо из полей**, даже если вы ещё не нажали Save.
- На время запроса кнопка блокируется (защита от даблкликов).
- Результат появляется строкой под кнопкой и дублируется в лог:
  - зелёным — «Тест пройден, сообщение отправлено»;
  - красным — код и текст ошибки от Telegram, например
    `401: Unauthorized` (неверный токен) или `400: chat not found` (неверный chat_id).
- Если поля пустые, запрос не уходит: сразу «Заполните токен и chat_id».

## Быстрое вкл/выкл из чата

Чтобы не лезть каждый раз в настройки, глобальный выключатель продублирован
командой. Значение сразу пишется в `config/afk-notifier.json`.

```
#tgnotification true     — включить уведомления
#tgnotification false    — выключить
#tgnotification          — показать текущее состояние и подсказку
```

Сообщение перехватывается на клиенте и **на сервер не уходит** — другие игроки
его не увидят.

### Подсказки по Tab

Автодополнение в чате умеет строить только brigadier, а он разбирает строки,
начинающиеся со слэша. Поэтому у команды есть второй, полностью равнозначный
вариант — с ним `true`/`false` подсказываются по Tab:

```
/tgnotification true
/tgnotification false
```

Обе формы делают одно и то же, пользуйтесь любой. Для `#`-варианта подсказка
печатается текстом: при пустом или непонятном аргументе мод отвечает
`Использование: #tgnotification <true|false>`.

### Хоткей

То же самое переключается с клавиатуры — по умолчанию **F6** (в ваниле клавиша
свободна). Нажатие переключает состояние на противоположное и пишет результат
в чат, как и команда.

Переназначить: **Настройки → Управление → Разное → «Вкл/выкл уведомлений в Telegram»**.

> Команда и хоткей переключают только глобальный выключатель (`Включить мод`).
> Галочки по отдельным событиям остаются в настройках.

## Свои тексты уведомлений

Тексты сообщений лежат отдельными файлами и правятся как обычный текст.
При первом запуске мод создаёт их сам:

```
.minecraft/config/afk-notifier/templates/
├── damage.txt
├── death.txt
├── disconnect.txt
├── connect.txt
└── README.txt      ← список подстановок
```

Открыть нужный файл можно прямо из игры: **Mods → AFK Notifier → шестерёнка →
вкладка «Шаблоны»**, кнопка «Открыть файл» рядом с событием. Файл откроется
в редакторе по умолчанию для вашей ОС. Там же есть кнопка «Открыть папку».

**Правки применяются сразу** — перезаходить в игру не нужно. Мод сверяет время
изменения файла перед каждой отправкой.

### Подстановки

В фигурных скобках подставляются значения:

| Файл | Доступно |
|---|---|
| `damage.txt` | `{time}` `{damage}` `{hp}` `{maxhp}` |
| `death.txt` | `{time}` `{deathmessage}` |
| `disconnect.txt` | `{time}` `{reason}` |
| `connect.txt` | `{time}` `{server}` |

Пример — `damage.txt`:

```
🩸 Получен урон
🕐 {time}
💥 Урон: {damage} HP
❤️ Текущее HP: {hp}/{maxhp}
```

Несколько правил:

- Опечатка в имени подстановки не ломает отправку — `{hpp}` просто уйдёт
  в сообщение как есть, так что ошибку видно сразу
- Значения, которые не удалось определить, подставляются словами
  («не определена», «неизвестен») — пустых строк в сообщении не будет
- Удалили файл — он создастся заново со стандартным текстом
- Пустой файл игнорируется, уйдёт стандартный текст

### Про символы

Экранировать ничего не нужно. Текст уходит в Telegram как есть, разметка
(Markdown/HTML) не включена, а тело запроса URL-кодируется — поэтому `&`, `%`,
`#`, `*`, подчёркивания, скобки, кавычки, эмодзи и переносы строк безопасны
и запрос сломать не могут.

Единственное ограничение — **длина: 4096 символов** на сообщение (лимит
Telegram). Более длинный текст мод обрежет сам и поставит многоточие, а не
получит отказ от API.

Текст тестового сообщения намеренно не редактируется: он нужен для проверки
связи и должен оставаться узнаваемым, даже если остальные тексты переписаны.

## Что приходит в Telegram

Время — локальное время системы, формат `dd.MM.yyyy HH:mm:ss`.

```
🩸 Получен урон
🕐 05.08.2026 14:30:12
💥 Урон: 3 HP
❤️ Текущее HP: 17/20

💀 Бот для фарма умер
🕐 05.08.2026 14:31:02
📜 Steve was slain by Zombie

🔌 Отключение от сервера
🕐 05.08.2026 14:35:44
📋 Причина: Timed out

✅ Подключение к серверу
🕐 05.08.2026 14:36:10
🌐 Сервер: play.example.com
```
